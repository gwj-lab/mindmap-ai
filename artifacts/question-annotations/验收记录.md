# 原位概念标记与答疑批注验收

验证范围：ChatGPT、腾讯元宝、豆包、DeepSeek、Kimi。

## 修复与交互

- 统一划取与恢复使用的文字范围，处理行内代码、公式上下文和首尾空格；兼容旧上下文。
- 正文替换后重新挂载标记层，重新定位；字体、图片、窗口尺寸和正文变化触发更新。只读阅读器仍显示已有标记。
- 紫色圆角标记表示概念；青色下划线表示答疑，两者可绑定同一段文字。
- 划取后单击“答疑”打开预填、可编辑的问题框。回答作为批注绑定原文，不增加候选节点、概念节点或导图节点。
- 单击下划线打开批注卡片；底部答疑列表保留访问入口。重试保留自定义问题，重启后恢复绑定。
- Markdown 答疑文档保存问题和来源引用，来源文档保存批注链接。

## 验证结果

- `pnpm test`：41 个测试文件，238 项全部通过。
- `pnpm typecheck`、`pnpm lint`、`pnpm build`：全部通过。
- 最终构建上的 `questions.spec.ts`、`concepts.spec.ts`、`reader-workspace.spec.ts`：9 项全部通过。
- 富格式回归 `rich-providers.spec.ts`：3 项通过。
- 五平台均完成阅读器划取和生产网站 preload 划取 → 编辑问题 → 自动生成截取 → 批注查看 → 重启恢复。
- 检查了概念与答疑的节点隔离、表格与代码显示、侧栏切换、最大化和滚动后的标记位置。

平台流程使用隔离 Electron 网页回放和生产 preload、IPC、存储与阅读器，模拟网站回答；本轮未使用在线账户发送答疑请求。
