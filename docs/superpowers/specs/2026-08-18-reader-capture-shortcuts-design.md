# 回答渲染、双击捕获与导图快捷键修复设计

## 目标

修复三类直接影响核心工作流的问题：本地回答阅读器不能正确显示 LaTeX 公式、ChatGPT 引用链接的小图标尺寸异常、导图节点的 XMind 风格快捷键在实际焦点状态下不响应。同时把网页悬停捕获从“停留后自动保存”改为“悬停识别、双击确认捕获”，并沿用工具栏当前选择的单一节点或生成子节点模式。

## 已确认交互

- 开启“悬停捕捉”后，鼠标所在的单条 ChatGPT 助手回答立即显示高亮，但仅双击高亮回答才执行捕获。
- 多轮对话中只捕获双击所在的那条助手回答，不包含相邻用户消息或其他回答。
- 双击捕获读取项目当前的捕获模式；选择“单一节点”时生成一个候选根节点，选择“生成子节点”时生成根节点及提取出的子节点。
- 正在流式输出的回答可以高亮，但双击不会保存，并显示明确的等待完成提示。
- “捕获最新回答”和“页面点选”入口继续保留，行为不受影响。

## 技术设计

### Markdown 与公式渲染

回答捕获仍将 ChatGPT 的 KaTeX/MathJax DOM 转换为标准 `$...$` 与 `$$...$$` Markdown。阅读器在 `react-markdown` 的 remark 阶段增加 `remark-math`，再由现有 `rehype-katex` 生成安全的 KaTeX HTML。这样不通过正则替换 Markdown，也不改变项目文件的可移植格式。

链接和图片继续经过现有 HTTPS 协议过滤。阅读器为 Markdown 图片提供语义化渲染：链接内部的图片视为 favicon/引用图标，限制在约 14×14 像素并与文字基线对齐；独立图片仍按正文内容图片处理，最大宽度为容器宽度并保持比例。链接图标加载失败时隐藏破损图标，不影响链接文字。

### 悬停与双击捕获

`HoverCaptureController` 只负责当前助手回答的命中、高亮、双击监听和状态徽标，不再维护 600ms 自动捕获计时器。控制器在捕获期间锁定当前目标，防止一次双击产生重复请求；捕获结束后显示“已捕获”“已存在”或失败提示。

DOM 变化监听仅用于判断流式状态变化和维持目标有效性。捕获载荷仍通过现有隔离 preload、Zod IPC 校验和主进程事务保存链路处理，因此候选节点及子节点生成自动使用项目中已经保存的 `captureMode`，远程页面无法直接选择磁盘路径或修改本地状态。

### XMind 风格快捷键

继续复用 `simple-mind-map` 的命令系统，不再额外实现一套导图编辑逻辑。为其配置明确的快捷键启用判断：当焦点不在 input、textarea、select、contenteditable、CodeMirror 或弹窗控件内，且鼠标位于当前导图 SVG 时允许命令执行。这样可避免 FlexLayout 按钮或 SVG 焦点导致全部快捷键被默认过滤，同时不会在回答编辑器中误删节点。

首批验收映射：

| 快捷键 | 行为 |
| --- | --- |
| Tab / Insert | 新建子节点 |
| Enter | 新建同级节点；根节点不创建非法同级 |
| Delete / Backspace | 删除选中节点；根节点不可删除 |
| F2 / Space | 重命名节点 |
| Ctrl+C / Ctrl+X / Ctrl+V | 复制、剪切、粘贴节点 |
| Ctrl+Z / Ctrl+Y | 撤销、重做 |
| 方向键 | 在节点间导航 |
| Ctrl+Up / Ctrl+Down | 调整同级顺序 |
| Ctrl+Enter | 折叠或展开当前节点 |

现有回答节点双击打开阅读器的行为保持不变，标题编辑使用 F2、Space 或右键菜单。

## 错误处理与安全边界

- 无效或尚未完成的回答不写入 Markdown，也不创建候选节点。
- 双击捕获的 IPC 失败只在对应回答上显示失败徽标，不影响 ChatGPT 页面继续工作。
- KaTeX 解析错误以原始 TeX 文本降级显示，阅读器不崩溃。
- Markdown URL 继续只允许 HTTPS 与 mailto；不开放原始 HTML、脚本、内联事件或本地文件协议。
- 导图快捷键在任何文本编辑上下文中禁用，防止 Backspace/Delete 等操作误删节点。

## 测试与验收

- 组件测试覆盖行内公式、块公式、引用链接小图标和普通正文图片的不同渲染结果。
- 捕获控制器契约测试覆盖悬停只高亮、单击不捕获、双击只捕获当前回答、防重复触发、流式回答拒绝及关闭开关。
- 导图快捷键单元测试覆盖可编辑目标过滤与 SVG/普通焦点放行；组件或 Electron 测试覆盖 Tab、Enter、Delete 的真实命令结果。
- 运行完整 Vitest、TypeScript、ESLint、构建和 Electron Playwright 测试。
- Windows 实机打开含公式与引用图标的已保存回答，检查视觉尺寸；在 ChatGPT 多轮页面分别用两种模式双击指定回答；点击节点后验证 XMind 快捷键。

## 非目标

- 本次不更换 Markdown 编辑器、导图库或捕获存储架构。
- 不下载远程引用图标或正文图片到本地。
- 不修改 AI 标题/子节点提取算法，也不新增其他 AI 网页适配器。
