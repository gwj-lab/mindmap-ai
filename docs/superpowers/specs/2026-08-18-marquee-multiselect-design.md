# 思维导图框选与多选操作设计

## 目标

为思维导图增加符合桌面导图软件习惯的框选能力：用户可以在画布空白处用鼠标左键拖出选框，一次选中多个节点，并对选中节点执行复制、剪切和批量删除。首版继续复用 `simple-mind-map` 的节点选择与命令体系，不自行实现画布命中引擎。

## 已确认交互

- 在画布空白处按住鼠标左键拖动超过 10 像素后开始框选。
- 与选框发生相交的节点进入多选，不要求节点完全包含在框内。
- 在节点上按住左键拖动继续执行节点移动，不触发框选。
- 鼠标右键或中键拖动画布；普通右键单击节点继续打开节点菜单。
- Ctrl+单击节点追加或取消单个节点；单击画布空白处清除当前选择。
- 多选后支持 Ctrl+C、Ctrl+X、Ctrl+V 和 Delete/Backspace。
- 首版不支持多节点一起拖动换父级，也不支持批量修改节点样式。

## 架构与数据流

### 框选与选择状态

`MindMapPanel` 已注册 `simple-mind-map` 的 `Select` 插件。本次启用其 `useLeftKeySelectionRightKeyDrag` 配置，使插件用左键在空白画布创建选框，同时让导图库的事件层将右键或中键拖动解释为画布平移。

选框超过插件内置的 10 像素阈值后显示；插件按节点矩形与选框是否相交维护 `renderer.activeNodeList`。Ctrl+单击继续使用现有 `enableCtrlKeyNodeSelection` 配置，因此框选和逐个追加共享同一份选择状态。框选本身是临时 UI 状态，不写入 `mindmap.json`、`map.md` 或项目工作区状态。

### 复制、剪切与粘贴

多选复制和剪切继续调用 `simple-mind-map` 已注册的 Ctrl+C、Ctrl+X、Ctrl+V 命令。应用不复制或维护第二份剪贴板选择状态。粘贴后的节点变化通过现有 `data_change` 事件进入项目自动保存流程。

### 批量删除与垃圾箱

现有 Delete/Backspace 只把最后一个活动节点传给应用层，因此需要将删除接口扩展为一组节点 UID。`MindMapPanel` 从 `renderer.activeNodeList` 读取全部活动节点，过滤根节点后一次提交给项目状态更新。

项目状态新增纯函数 `trashPortableSubtrees(snapshot, nodeUids, options?)`。它首先去重并剔除根节点，然后过滤掉“祖先也被选中”的后代 UID。剩余的每个顶层选中子树分别生成一条可恢复的垃圾箱记录，并在一次不可分割的状态更新中从导图移除。这样父子同时被框选时不会生成重复或残缺记录，恢复任意垃圾项仍使用现有恢复流程。

右键菜单仍以被右键点击的单个节点为操作对象；如果右键点击改变了活动选择，导图库会按现有规则收敛为该节点。工具栏删除按钮和 Delete/Backspace 则删除当前全部活动节点。

## 边界与错误处理

- 根节点即使落入选框也不能被删除、剪切或拖入垃圾箱。
- 只读项目沿用 Select 插件的只读保护，不创建选框，也不执行批量删除。
- 空选择、重复 UID、不存在的 UID 均作为无操作处理，不产生空垃圾记录。
- 若选中父节点及任意深度后代，仅父节点进入垃圾箱；未选择父节点的多个兄弟节点分别成为可独立恢复的垃圾项。
- 框选结束、指针离开画布或鼠标释放时清理临时选框；自动滚动画布沿用 Select 插件实现。
- 节点回答关联和子树中的自定义字段随原子子树一起进入垃圾箱，不丢失 `answerId`。

## 测试与验收

- 项目状态单元测试：批量删除兄弟节点、父子去重、根节点保护、不存在 UID、回答关联字段保留及分别恢复。
- 导图组件/策略测试：配置启用左键框选和 Ctrl 多选，删除命令读取完整活动列表而不是最后一个节点。
- Electron 集成测试：创建多个节点，左键拖框命中至少两个节点，按 Delete 后两者同时消失并生成对应垃圾记录；右键拖动不会出现选框；节点右键菜单仍可打开。
- 回归运行完整 Vitest、TypeScript、ESLint、构建和 Playwright Electron 测试。

## 开源复用结论

直接复用已安装的 MIT 许可 `simple-mind-map` Select 插件。该插件已经提供框选矩形、节点相交检测、活动节点列表、Ctrl 多选与边缘自动滚动；应用只配置鼠标模式并补充便携项目垃圾箱所需的批量删除语义。无需引入新依赖或自研框选算法。

## 非目标

- 不实现多选节点整体拖动或统一换父级。
- 不实现批量颜色、字体、边框或形状编辑。
- 不保存上次关闭项目前的选择状态。
- 不改变候选节点和历史节点的拖放交互。
