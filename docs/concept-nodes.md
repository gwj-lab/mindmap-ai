# 概念节点使用说明

## 生成与阅读

1. 在已保存回答的预览中，或者 ChatGPT、腾讯元宝、豆包的助手回答中，按住鼠标左键划选概念词。
2. 选词原位出现圆角框，没有关闭符号。再次点击框生成概念；点击其他区域或按 Esc 取消。
3. 应用新开所选网站的问答标签页，提交包含完整原句的提示词。回答生成完毕且稳定后，使用该网站原有的格式保存器保存。
4. 生成完成后，原位标记成为概念链接。点击打开概念笔记；笔记中的来源区域可以返回原文并聚焦选词。
5. 在候选节点面板的“概念节点”区域阅读、改名或拖入导图。导图节点带“概念”标签；正文编辑、节点历史和节点垃圾箱复用现有功能。概念库的删除和恢复在同一个垃圾箱页完成。

概念库属于工作区，可在不同项目中复用。同名词的原句或主题不同，会建立独立概念，以免混淆含义。引用概念的导图节点被移走或删除后，库中的概念仍可继续使用。

## 设置

点击“概念节点”右侧的“设置”：

- **生成网站**：跟随来源平台，或固定使用 ChatGPT、腾讯元宝、豆包。
- **后台生成**：不切换当前阅读器或标签页；关闭时显示新生成页面。
- **提示词模板**：必须包含 `{concept}`（选词）和 `{sentence}`（完整原句），可包含 `{title}`（当前节点标题）。

默认示例：

> 当前主题是“回归模型”。原文中的完整句子是：“残差是观测值与预测值之差。”请解释这句话中“残差”的具体含义，结合当前主题说明它在这里的作用，并给出一个贴合语境的例子。请直接在聊天正文回答，不创建云端文档。

标题、列表项和表格单元格以所在项提供语境。代码块、公式和网页控件不支持概念划词；跨段落选区不生成，以避免提交不完整或混合的句子。选词最多 160 个字符。

## 保存与链接

正文保存在工作区 `answers/`；概念库与设置保存在 `concepts.json`。网站原页面划词时，完整来源回答会先保存为本地 Markdown。

原文的“概念引用”和概念笔记的“概念来源”使用标准相对 Markdown 链接。应用的原位选词链接还依赖 `concepts.json`；在 Obsidian 中可使用 Markdown 链接及反向链接浏览。编辑正文时应用保留概念引用；如果原句已经修改而无法唯一匹配，返回来源仍能阅读正文，但会提示无法精确定位。

删除库中词条先进入垃圾箱，可恢复。彻底移除词条会保留 Markdown，避免已有文档链接失效。独立项目导出包含可达的概念与来源 Markdown，不包含工作区生成设置。

## 网站自动生成的边界

请先在所选平台登录。登录、验证码、限流、页面结构变化或网络失败可能阻止自动提交或生成；库中保留失败状态，支持查看生成页面、处理登录后重试。超时约三分钟，重启后未完成的任务标为失败。

当前验证包括：真实网站输入框与发送控件的 DOM 校准，以及隔离 Electron 页面中使用生产 preload、IPC、保存器和阅读器的端到端测试。隔离测试模拟回答与流式结束，没有用真实登录账户完成一次在线自动生成。上线网站的账号状态和页面变更仍需人工验收。

## 开源复用取舍

链接使用 [Obsidian 官方文档中的 Markdown 内部链接](https://help.obsidian.md/links)。原位选区参考 [Recogito Text Annotator](https://github.com/recogito/text-annotator) 的文字定位思路；本次复用项目现有 Markdown、候选节点和导图组件，用浏览器 Range 绘制浮层，没有新增依赖。
