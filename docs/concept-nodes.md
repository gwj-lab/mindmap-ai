# 概念节点使用说明

## 生成与阅读

1. 在已保存回答的预览中，或者 ChatGPT、腾讯元宝、豆包、DeepSeek、Kimi 的助手回答中，按住鼠标左键划选概念词。
2. 选词原位出现圆角框，没有关闭符号。再次点击框生成概念；点击其他区域或按 Esc 取消。
3. 应用在所选网站提交包含完整原句的提示词。前台模式新开问答标签页；后台模式使用隐藏网页视图，不增加标签栏选项，完成后自动释放。回答生成完毕且稳定后，使用该网站原有的格式保存器保存。
4. 生成完成后，原位标记成为概念链接。在节点阅读器中点击，会在右侧展开概念预览；完整打开后，笔记中的来源区域可以返回原文并聚焦选词。
5. 在候选节点面板的“概念节点”区域阅读、改名或拖入导图。导图节点带“概念”标签；正文编辑、节点历史和节点垃圾箱复用现有功能。概念库的删除和恢复在同一个垃圾箱页完成。

概念库属于工作区，可在不同项目中复用。同名词的原句或主题不同，会建立独立概念，以免混淆含义。引用概念的导图节点被移走或删除后，库中的概念仍可继续使用。

## 阅读窗口与概念侧栏

- 双击导图中带正文的节点，可以同时打开多个阅读窗口。再次打开同一篇笔记，会将已有窗口置前。
- 拖动窗口标题栏调整位置，拖动右下角调整大小；点击“最大化窗口”或双击标题栏铺满阅读工作区，再点击“还原窗口”恢复原来的大小和位置。
- 底部窗口栏切换已打开的笔记。“工作区”隐藏窗口并显示问答页面；点击窗口标题或“显示窗口”可继续阅读，隐藏时保留未保存编辑。
- 节点关联的概念集中显示在右侧。单击概念标题展开预览，其余标签只显示标题；再次单击收起。生成中的概念会显示进度状态。
- 双击展开预览的空白处，或点击标签右上角的完整打开按钮，将概念显示在主阅读区。点击左上角的回退箭头返回节点页面，保留阅读位置与编辑内容。
- 编辑笔记后点击“保存”，或在阅读器中按 `Ctrl+S`。关闭包含未保存编辑的窗口时会提示确认。
- 阅读器采用浅灰面板、紫色选中态与细分隔线；右侧概念栏可以收起，为正文留出更多空间。

## 答疑批注

- 划取文字后，单击旁边的“答疑”按钮，打开预填了主题、原句和所选文字的自定义问题框；可以修改整段问题后发送。
- 答疑使用当前概念设置中的生成网站和后台模式。回答自动截取并绑定原文，用青色下划线表示；概念继续用紫色圆角标记。
- 单击下划线打开批注卡片，查看问题与完整格式的回答；阅读器底部的答疑列表也可访问同一原文的多个问题。失败时可以重试，重试保留自定义问题。
- 答疑不是节点，不进入候选托盘、概念侧栏或导图。独立 Markdown 保存问题和来源引用；来源文档追加“答疑批注”链接，便于在应用之外查看。
- 原位标记会在正文重绘、字体加载、窗口变化后重新定位；滚动和拖动跟随原文。关闭阅读器或重启后仍可恢复。若原文改动导致无法唯一定位，答疑列表和 Markdown 引用仍可访问回答。

## 设置

点击“概念节点”右侧的“设置”：

- **生成网站**：跟随来源平台，或固定使用 ChatGPT、腾讯元宝、豆包、DeepSeek、Kimi。
- **后台生成**：不切换当前阅读器或标签页，不新增可见标签页，结束后关闭隐藏页面。主动点击“查看生成页面”时才显示标签页；后台任务成功后该临时标签页也自动关闭。前台模式的标签页由用户关闭。
- **提示词模板**：必须包含 `{concept}`（选词）和 `{sentence}`（完整原句），可包含 `{title}`（当前节点标题）。

默认示例：

> 当前主题是“回归模型”。原文中的完整句子是：“残差是观测值与预测值之差。”请解释这句话中“残差”的具体含义，结合当前主题说明它在这里的作用，并给出一个贴合语境的例子。请直接在聊天正文回答，不创建云端文档。

标题、列表项和表格单元格以所在项提供语境。代码块、公式和网页控件不支持概念划词；跨段落选区不生成，以避免提交不完整或混合的句子。选词最多 160 个字符。

## 保存与链接

正文保存在工作区 `answers/`；概念库与设置保存在 `concepts.json`。网站原页面划词时，完整来源回答会先保存为本地 Markdown。

原文的“概念引用”和概念笔记的“概念来源”使用标准相对 Markdown 链接。应用的原位选词链接还依赖 `concepts.json`；在 Obsidian 中可使用 Markdown 链接及反向链接浏览。编辑正文时应用保留概念引用；如果原句已经修改而无法唯一匹配，返回来源仍能阅读正文，但会提示无法精确定位。

已生成词条的原位圆角高亮持续保留，点击可预览解释。文字高亮由浏览器绘制，可点击区域锚定在正文内，随正文滚动或窗口拖动同步移动。点击其他区域只取消尚未生成的临时选词框及浏览器蓝色选区，不移除已有概念高亮。

删除库中词条先进入垃圾箱，可恢复。彻底移除词条会保留 Markdown，避免已有文档链接失效。独立项目导出包含可达的概念与来源 Markdown，不包含工作区生成设置。

## 网站自动生成的边界

请先在所选平台登录。登录、验证码、限流、页面结构变化或网络失败可能阻止自动提交或生成；库中保留失败状态，支持查看生成页面、处理登录后重试。超时约三分钟，重启后未完成的任务标为失败。

当前验证包括：真实网站输入框与发送控件的 DOM 校准，以及隔离 Electron 页面中使用生产 preload、IPC、保存器和阅读器的端到端测试。隔离测试模拟回答与流式结束，没有用真实登录账户完成一次在线自动生成。上线网站的账号状态和页面变更仍需人工验收。

## 开源复用取舍

链接使用 [Obsidian 官方文档中的 Markdown 内部链接](https://help.obsidian.md/links)。原位选区参考 [Recogito Text Annotator](https://github.com/recogito/text-annotator) 的文字定位思路。阅读工作区继续复用现有 FlexLayout、CodeMirror、Markdown 与图标组件；采用 [CSS Custom Highlight API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Custom_Highlight_API) 和正文内的 Range 点击区域，没有新增依赖。
