# Windows 10/11 manual acceptance checklist

## ChatGPT and capture

- [ ] 登录 ChatGPT，重启应用后登录状态仍有效；应用未请求账号密码。
- [ ] 在多轮对话中悬停某一条助手回答，只高亮并捕获该回答。
- [ ] 流式输出期间不捕获；稳定后双击悬停高亮的回答可捕获。
- [ ] 关闭悬停识别后双击不处理；“捕获最新”和“点选回答”仍可用。
- [ ] 含标题、表格、代码、行内公式和块公式的回答生成正确 Markdown。
- [ ] 同一条 ChatGPT 回答连续捕获三次得到三个独立候选；删除其中一个后仍可再次捕获。

## Nodes and trays

- [ ] “单一节点”只生成根候选；“生成子节点”生成有序子节点。
- [ ] 候选根标题和子标题可编辑、排序、移除，再作为完整子树拖入导图。
- [ ] 右键节点可重命名、创建子/同级节点、移入历史或删除；根节点受保护。
- [ ] 节点可拖入历史区并恢复到任意导图节点。
- [ ] 候选、历史和导图删除项进入垃圾箱；恢复与彻底删除行为正确。
- [ ] 答案关联节点显示内容角标；多节点模式生成的纯标题子节点不显示角标。
- [ ] 保存、关闭并重新打开工作区后，内容角标仍按答案关联正确显示。
- [ ] Tab、Enter、F2、Delete、Ctrl+C/X/V/Z/Y、Ctrl+Enter、方向键与 XMind 习惯一致。

## Projects, persistence, and portability

- [ ] “新建主项目”和“创建子项目”均打开应用内命名框；Enter 提交，Esc 取消，失败信息留在框内。
- [ ] 创建主项目和子项目时，切换前未保存内容会先保存。
- [ ] 修改导图、停靠布局、主题和托盘后关闭应用；重开全部恢复。
- [ ] 删除某项目的 `mindmap.json` 后仍能从 `map.md` 打开并重建 JSON。
- [ ] 将工作区作为 Obsidian vault 打开，`map.md` 大纲、Mermaid 和回答链接可读。
- [ ] 导出独立项目后，所有 `answers/<id>.md` 相对链接均存在。
- [ ] 项目移入垃圾箱后可恢复；彻底删除前出现确认。
- [ ] 断网后仍可编辑导图和已保存回答。

## API and security

- [ ] 未配置 API 时本地提取正常。
- [ ] 左侧“API 配置”和 AI 面板齿轮打开同一配置页，返回后原导图布局不变。
- [ ] API 密钥输入后 UI 只显示保存状态，工作区及导出文件中找不到明文密钥。
- [ ] 更改已绑定密钥的 Base URL 会再次确认；HTTP 地址被拒绝。
- [ ] API 超时或返回错误时自动使用本地标题，回答和候选仍保存。
- [ ] 远程页面不能访问 Node 或任意本地路径；摄像头、麦克风、通知和文件权限默认拒绝。
- [ ] 非 ChatGPT/OpenAI/OAuth 外链需要确认并交给系统浏览器。
